이차함수,
꼭짓점과 판별식

이차함수는 중3에서 처음 배우고 고1 공통수학1에서 이차방정식과 함께 다시 깊게 다룹니다. 표준형으로 바꾸는 연습이 모든 문제의 출발점입니다.

이차함수의 두 가지 형태

  • 일반형 — y = ax² + bx + c (a ≠ 0)
  • 표준형 — y = a(x − p)² + q

표준형에서 꼭짓점은 (p, q), 축의 방정식은 x = p입니다. y = a(x − p)² + q의 그래프는 y = ax²의 그래프를 x축의 방향으로 p만큼, y축의 방향으로 q만큼 평행이동한 것입니다.

일반형을 표준형으로 바꾸기

예: y = x² − 4x + 1

  1. x² − 4x를 완전제곱식으로 만들기 위해 (−4 ÷ 2)² = 4를 더하고 뺍니다.
  2. y = (x² − 4x + 4) − 4 + 1
  3. y = (x − 2)² − 3
  4. 꼭짓점 (2, −3), 축의 방정식 x = 2

일반형에서 바로 구할 때는 꼭짓점의 x좌표가 −b/(2a)라는 것을 이용할 수 있습니다.

그래프의 모양

  • a > 0이면 아래로 볼록, a < 0이면 위로 볼록
  • |a|가 클수록 그래프의 폭이 좁아집니다.
  • y절편은 x = 0을 대입한 값으로, 일반형에서 c입니다.

판별식과 x축의 위치 관계 (고1)

이차함수 y = ax² + bx + c의 그래프와 x축의 교점은 이차방정식 ax² + bx + c = 0의 실근과 같습니다. 판별식 D = b² − 4ac로 위치 관계를 판단합니다.

판별식이차방정식의 근그래프와 x축
D > 0서로 다른 두 실근서로 다른 두 점에서 만난다
D = 0중근한 점에서 만난다(접한다)
D < 0서로 다른 두 허근만나지 않는다

자주 묻는 질문

이차함수 꼭짓점은 어떻게 구하나요?+

식을 y = a(x − p)² + q 꼴로 바꾸면 꼭짓점은 (p, q)입니다. 일반형에서는 x좌표 −b/(2a)를 구해 식에 대입해도 됩니다.

축의 방정식은 무엇인가요?+

이차함수 그래프의 대칭축을 나타내는 직선으로, 꼭짓점의 x좌표가 p이면 x = p입니다.
