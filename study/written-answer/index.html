수학 서술형,
감점 없이 쓰는 법

답은 맞았는데 점수가 깎였다면 대부분 풀이 과정의 문제입니다. 서술형은 채점자가 무엇을 보는지 알면 점수를 지키기 쉬워집니다.

채점 기준에서 보는 것

  1. 미지수와 조건 설정 — 무엇을 x로 두었는지 밝혔는가
  2. 식 세우기 — 문제의 조건을 식으로 옮겼는가
  3. 풀이 과정 — 계산의 흐름이 논리적으로 이어지는가
  4. 답과 확인 — 조건에 맞는 답을 단위와 함께 썼는가

답안 작성 순서

예를 들어 "연속하는 두 자연수의 합이 25일 때 두 수를 구하라"는 문제라면 다음 순서로 씁니다.

  1. 작은 수를 x라 하면 큰 수는 x + 1이다.
  2. x + (x + 1) = 25
  3. 2x + 1 = 25, 2x = 24, x = 12
  4. 따라서 두 수는 12, 13이다. (12 + 13 = 25이므로 조건을 만족한다.)

자주 감점되는 실수

  • 미지수를 정하지 않고 바로 식을 쓰는 경우
  • 중간 계산을 생략해 풀이가 끊기는 경우
  • 이차방정식의 해 중 조건(길이는 양수 등)에 맞지 않는 값을 버리지 않은 경우
  • 단위를 빠뜨리거나 묻는 것과 다른 값을 답으로 쓴 경우
  • 등호를 연결해서 쓰면 안 되는 곳에 이어 쓴 경우
