인수분해 공식,
한 번에 정리

인수분해는 이차방정식, 이차함수, 고등 다항식까지 계속 쓰이는 도구입니다. 공식 암기보다 어떤 공식을 쓸지 알아보는 눈이 중요합니다.

인수분해의 뜻

하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것을 인수분해라고 합니다. 전개의 반대 과정입니다.

중3 인수분해 공식

  1. ma + mb = m(a + b) — 공통인수로 묶기
  2. a² + 2ab + b² = (a + b)²
  3. a² − 2ab + b² = (a − b)²
  4. a² − b² = (a + b)(a − b)
  5. x² + (a + b)x + ab = (x + a)(x + b)
  6. acx² + (ad + bc)x + bd = (ax + b)(cx + d)

인수분해 순서

  1. 공통인수가 있으면 먼저 묶습니다.
  2. 항이 두 개면 합차 공식, 세 개면 완전제곱식이나 이차식 공식을 떠올립니다.
  3. 복잡한 식은 반복되는 부분을 한 문자로 치환합니다.
  4. 더 이상 인수분해되지 않을 때까지 확인합니다.

예: 2x² − 8 = 2(x² − 4) = 2(x + 2)(x − 2)

고1 공통수학1에서 추가되는 공식

  • a³ + 3a²b + 3ab² + b³ = (a + b)³
  • a³ − 3a²b + 3ab² − b³ = (a − b)³
  • a³ + b³ = (a + b)(a² − ab + b²)
  • a³ − b³ = (a − b)(a² + ab + b²)

삼차식은 인수정리로

다항식 P(x)에서 P(α) = 0이면 P(x)는 x − α를 인수로 가집니다. 예를 들어 P(x) = x³ − 2x² − x + 2에서 P(1) = 0이므로 x − 1로 나누면(조립제법) P(x) = (x − 1)(x² − x − 2) = (x − 1)(x + 1)(x − 2)입니다.
